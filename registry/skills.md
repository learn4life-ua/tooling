# Skills Registry

Статуси:

- `APPROVED` — можна використовувати у робочих проєктах.
- `TESTING` — тільки для контрольованих тестів.
- `ADVANCED` — підключати за конкретної потреби.
- `REFERENCE` — приклад або джерело ідей, не частина toolchain.
- `REJECTED` — не використовувати.
