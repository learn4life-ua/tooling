# Learn4Life Ukrainian glossary

Use these preferred forms consistently unless an exact quotation, registered name, official title, or user-provided wording must be preserved.

## Preferred forms

| Use | Avoid / review |
|---|---|
| вебсайт | веб-сайт |
| проєкт | проект |
| онлайн | он-лайн |
| офлайн | оф-лайн |
| соціальні мережі | соцмережі in formal or methodological prose; allowed in informal social copy when context supports it |
| здобувач освіти | студент, учень, слухач when the official educational context specifically requires «здобувач освіти» |
| навчальне заняття | урок when the educational form is not legally or institutionally an урок |
| розв’язування задач | вирішення задач, рішення задач in mathematics |
| розв’язок задачі | рішення задачі in mathematics |
| критерії оцінювання | критерії оцінки when referring to formal assessment criteria |
| поточне оцінювання | поточний контроль when the intended meaning is assessment rather than a formal control measure |
| тематичне оцінювання | тематичний контроль when the intended meaning is assessment rather than a control activity |
| підсумкове оцінювання | підсумковий контроль when the intended meaning is assessment rather than a formal control measure |

## Project and brand names

Preserve these names exactly when they refer to the project or product:

- `CashBrain`
- `Learn4Life`
- `Codex`
- `GitHub`
- `WordPress`

Do not translate, respell, or alter brand capitalization unless the official brand itself changes.

## Rule for institutional and programme names

Do not guess or normalize an official institution, educational programme, department, qualification, law, order, regulation, or document title from memory.

If the exact official form is present in the source, preserve it. If a correction is needed and the exact current form is not certain, verify it before changing the text.

## Mathematical language

Prefer established Ukrainian mathematical terminology and notation. In prose:

- `розв’язати рівняння`;
- `розв’язування задач`;
- `знайти значення виразу`;
- `побудувати графік функції`;
- `область допустимих значень`;
- `область визначення функції`.

Do not replace precise mathematical terms with conversational synonyms.
