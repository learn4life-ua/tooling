# Ukrainian anti-calques and common corrections

Use this list as an editing aid, not as a blind replacement table. Preserve meaning, quotations, official wording, and specialist terminology. If a correction could change the intended meaning, do not guess.

## Common non-normative or undesirable forms

| Prefer | Avoid / review |

| брати участь | приймати участь |
| є | являється |
| становить | складає, when the meaning is a numerical total or amount |
| становити частину | складати частину, when used as a calque |
| щодо | по питанню, по темі |
| з питання | по питанню |
| відповідно до | у відповідності до |
| згідно з | згідно |
| протягом | на протязі, when referring to time |
| під час | у ході, when a simpler temporal meaning is intended |
| наступний | слідуючий |
| такий | даний, when `даний` merely means «цей» |
| цей документ | даний документ |
| нині / тепер / зараз | на даний момент |

| обсяг | об’єм, when referring to quantity of work, text, funding, data, etc. |
| кількість | число, when referring to countable objects rather than a mathematical number |
| виняток | виключення, when the meaning is exception rather than exclusion |

| навчальний | учбовий |

## Editing rule

Do not replace a word merely because it appears in the right-hand column. Check context first.

Examples:

- `об’єм кулі` is correct in geometry; `об’єм роботи` is not.
- `виключення з переліку` may describe an action of exclusion; `за виключенням` should normally be `за винятком`.
- `проходити` is correct for movement or a process that literally passes; for an event, prefer `відбуватися`.

## Bureaucratic padding

When meaning is unchanged, simplify phrases such as:

- `з метою здійснення` → `для`;
- `у зв’язку з тим, що` → `оскільки`, `через те що` or another context-appropriate form;
- `має місце` → state the fact directly;
- `проводити роботу щодо` → name the actual action;
- `здійснювати реалізацію` → `реалізовувати`;
- `здійснювати контроль` → `контролювати`, unless the noun phrase is required by official terminology.

Prefer concise natural Ukrainian, but do not oversimplify legal, administrative, or methodological wording when exact terminology matters.
