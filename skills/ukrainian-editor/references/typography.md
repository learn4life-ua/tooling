# Ukrainian typography house style

Apply these rules to ordinary Ukrainian prose unless an exact source or another publication style must be preserved.

## Dashes and hyphens

- Do not use the em dash `—` in Learn4Life final prose.
- Use the en dash `–` for punctuation dashes: `Освіта – це процес.`
- Put spaces around a punctuation dash.
- Use the en dash without spaces for ranges: `2025–2026`, `с. 15–18`, `10–12 балів`.
- Use the hyphen `-` only where Ukrainian orthography or an exact technical string requires it.
- Distinguish punctuation dashes, range signs, and hyphens instead of replacing characters mechanically.

## Quotation marks

Use Ukrainian angle quotation marks `« »` as the default outer quotation marks in Ukrainian prose.

For a quotation inside another quotation, use `“ ”` when nested quotation marks are needed.

Preserve punctuation in exact quotations and official wording when changing it would alter the source.

## Apostrophe

Use a proper Ukrainian apostrophe consistently in ordinary prose. Preserve exact technical strings and quotations when fidelity matters.

## Spaces with symbols and units

Use a space between a number and a unit or symbol where appropriate:

- `25 %`;
- `10 км`;
- `5 кг`;
- `20 °C`;
- `№ 12`.

Prefer a non-breaking space in publication-ready text when the target format supports it.

## Dates and ranges

Preserve the date format required by the document or institution.

For prose, a fully written date is often clearer: `13 вересня 2026 року`.

For continuous ranges, use an en dash: `7–13 вересня 2026 року`.

## Numbers

Do not change factual numbers, percentages, scores, article numbers, order numbers, years, or identifiers unless correction is explicitly required and the correct value is verified.

Use the decimal comma in ordinary Ukrainian prose unless a technical format requires another notation.

## Lists and headings

- Avoid decorative bolding.
- Use sentence case for ordinary headings unless a source style requires otherwise.
- Keep list punctuation consistent.
- Do not add emojis to official, methodological, academic, or administrative text unless explicitly requested.

## Exact strings

Do not apply typographic substitutions inside code, commands, file paths, identifiers, repository names, version strings, or exact quotations when fidelity is required.
