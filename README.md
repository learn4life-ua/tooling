# Learn4Life Tooling

Центральний набір правил, skills і робочих процесів для освітніх вебпроєктів Learn4Life.

## Ядро

1. Effective HTML — швидке прототипування.
2. Taste Skill + Learn4Life UX/UI Standard — дизайн і контроль якості інтерфейсу.
3. Addy Osmani Agent Skills — дисципліна розробки.
4. NVIDIA SkillSpector — перевірка сторонніх skills.
5. Understand Anything — розуміння великих кодових баз.
6. Diagram Design — навчальні схеми та візуалізації.

## Принцип

Новий сторонній skill не використовується автоматично.

`candidate → security review → testing → approved/rejected`

Внутрішній UX/UI Standard має пріоритет над порадами зовнішніх design skills.

## Структура

- `standards/ux-ui-standard.md` — головний стандарт інтерфейсів.
- `registry/skills.md` — реєстр дозволених, тестових і відхилених skills.
- `security/skill-policy.md` — правила безпеки.
- `workflows/web-project.md` — базовий цикл створення вебпроєкту.
